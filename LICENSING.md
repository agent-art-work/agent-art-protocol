# Licensing

On 2026-10-24 the operator selected **MIT** for original Agent Art Protocol
code and documentation, including the original SDK, reference implementation
and developer tooling. The [LICENSE](LICENSE) contains the license text and
credits Agent Art Protocol contributors. Original contributor and source
attributions remain intact; that notice does not claim ownership of external
material.

MIT permits reuse, modification and commercial distribution while requiring
retention of the copyright and permission notice. It has no separate express
patent grant. See the [MIT text published by OSI](https://opensource.org/license/mit).
The operator chose MIT after comparing it with Apache-2.0 and copyleft
alternatives; the earlier Apache-2.0 recommendation is superseded.

## Scope

- The repository license covers original project material to the extent the
  contributors have authority to license it.
- Imported source, patch context, external documents, provider assets and
  third-party material retain applicable original rights and notices. The
  project license does not automatically relicense them. The outstanding
  review is recorded in the [publication audit](PUBLIC-ALPHA-AUDIT.md).
- Merely referencing an artwork, participant contribution, private record or
  linked repository does not place it under this license. Artists retain
  responsibility for the licensing of their own works.
- The original component mark is included as a reusable component asset.
  Reusing it does not establish endorsement or protocol conformance. This
  adoption creates no separate trademark or certification policy.

Preserve [SOURCE.md](SOURCE.md), pinned historical references and applicable
[upstream notices](THIRD-PARTY-NOTICES.md). MIT selection does not resolve disclosure permissions for
private-derived material, third-party redistribution rights or Git metadata.

## SDK and release boundary

The root source distribution now includes LICENSE and root package metadata
identifies MIT. **SDK 0.1.4 source files, package manifest, archive, installed
consumer, qualification pins and tag are unchanged.** The historical archive
predates adoption and contains no license file; this record does not assert
that its original distribution or qualification included MIT.

The prepared [0.1.5-alpha.1](releases/0.1.5-alpha.1/RELEASE.md) archive includes
MIT's text, contributor notice and package license field. Its runtime/type
files are copied only after checking them against the retained 0.1.4 source
digests; metadata and the standalone guide belong to the new alpha. It has a
new archive and consumer lock, with separate qualification. The operator
separately approved disclosure of this repository's existing history and
included material for public release. Third-party terms remain applicable.
Do not silently repack 0.1.4, move its tag or reuse its qualification
for changed package bytes.

License adoption alone does not authorize publication. The operator separately
approved making this repository public and publishing the 0.1.5-alpha.1 GitHub
prerelease on 2026-10-24. Registry publication, deployment, announcements to
other audiences and new live Agent trials are outside that authorization.
