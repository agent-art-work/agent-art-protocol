## Actual client encounter

A bounded noninteractive trial launched the installed Claude Code 2.1.278 with
existing client authentication, a 120-second adapter timeout and a USD 1 API
budget setting. The process exited successfully. A fresh restricted client
session read the conditions/opening through the MCP bridge and submitted a
response. The service retained two Acts and two Relations: the curator opening
addressed the Work, and the Agent connection's response addressed that opening.
The browser then recorded curator selection and displayed the exact accepted
Agent line. Service events included client-connected, context-offered,
acceptance and selection, with their limited source classes.

The real encounter's exported package was checked by the offline CLI. Retained
byte bindings, local authority attribution and the exact selected pair were
supported under the local operator-trust policy. Independent Agent execution
origin and website presentation proof remained not established. These results
are a scoped observation of a working local path, not transferable proof that
the entire native Agent process chose freely or has a particular private identity.
