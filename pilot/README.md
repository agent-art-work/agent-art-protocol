# Reading SDK pilots

The active pilot is **SDK 0.1.1 reading on Lab**. The package now owns the
selected compact Open bubble / Seal component: a small noninteractive
**Ask your Agent** label, ChatGPT desktop prefill, Claude and always-visible
Copy, on one line. The app supplies its exact public prompt and index. The
visitor asks and continues inside their Agent.

```sh
npm run pilot:lab
```

Open [Lab](http://127.0.0.1:4174/). The local host provides optional read-only
Mac app discovery; this callback is outside the SDK. Public sites need no
helper and can offer configured routes without claiming installation.
`--no-desktop-discovery` disables the local endpoint and exercises discovery-failure fallback; `--prepare-only` builds
without starting a server. The old `--open-gate` flag is harmless but unnecessary.

See the [active consumer guide](reading-sdk/README.md),
[current qualification](reading-sdk/QUALIFICATION.json), and
[SDK API guide](../protocol/README.md). Destination app mode is not forced.
Review and Send remain in the Agent. No questions, answers or private history
are collected by this component. Receipts are optional request observations.

The [four-consumer 0.1.0 guide](reading-consumers/README.md) and
[local design trials](open-gate/README.md) remain historical. Inshell, Pulse
and Signatures Gallery are not maintained as active test apps for this patch.
Their original owner checkouts and deployed sites are unchanged. THOUGHT
participation remains deferred to a later compatible release.

Earlier [Q&A and native-handoff observations](QUALIFICATION.md),
[alpha shared-consumer qualification](PROTOCOL-QUALIFICATION.md),
[Lab helper patch](lab-consumer.patch), [THOUGHT patch](thought-consumer.patch)
and [reading helper code](reading/) are preserved as historical experiments.
Their checks do not automatically qualify this release. Existing core exports
remain experimental; preserving the old THOUGHT bootstrap does not expand
0.1's supported reading scope or qualify a new artwork flow.
