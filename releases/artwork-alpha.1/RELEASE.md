## Proposed release notes

An artist and coding Agent can reuse a local participation/evidence runtime and
optional selected-account companion while building their own app and creative
rules. The SDK preserves exact permitted contributions, scoped receipts/recovery,
separate app Reports and selected inspection. The companion assembles a bounded
in-memory account over that same owner with independent app copy controls.

Qualified here: the named macOS arm64/Node22.23.4 cohort, exact installed fixture
proofs and the owner-reported fresh synthetic Signatures integration. The alpha
does not promise a universal Agent connector, production authentication, managed
hosting, independent model origin, safe SVG rendering or backup/restore. See
SUPPORT.md and QUALIFICATION.json. Audiences interpret intention and artistic value.
