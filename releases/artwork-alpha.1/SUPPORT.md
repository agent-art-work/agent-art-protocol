# Alpha support and trust limits

**Prepared artwork-alpha.1, not a public release or a stable protocol standard.**
Only the exact two package identities in [ARTIFACTS.json](ARTIFACTS.json) and the
named environment/compositions below have the stated evidence. A website release,
copied prompt or fixture success does not qualify another client or deployment.

## What this SDK supplies

| Area | Supported candidate boundary |
| --- | --- |
| Runtime | One existing version-2 SQLite owner per Work, native scoped participation and preserved exact UTF-8 originals |
| Participation | Explicit context/authority, durable exact preparation, contribution or explicit refusal, receipts, own status/cancel and finite recovery; no universal initiator or round count |
| MCP methods | Seven bounded raw tools via a trusted principal resolver; no initialization, transport, OAuth or running service supplied by this package |
| Consequence | Separate owner-issued app Reports and exact output DataRefs; facts supplied by the app retain their source and trust limits |
| Inspection | Existing selected Manifest/native reader; maximum 16 records/eight data entries, leases at most five minutes and clipped by actual rights |
| Account | Optional exact selected envelope/checker, separate inert projection and bounded collector over one captured local inspection facade |
| Media | Verified UTF-8 material, including opaque SVG/HTML-labelled text; external graphic outputs can be digest/length/media-type refs with missing bytes disclosed |
| Qualified cohort | macOS arm64, Node22.23.4, SQLite3.53.4, npm10.9.9; core/companion clean-consumer proof and named synthetic Signatures integration |

The owner-administrative collector mode has fake-port tests but no delivered
native admin-source adapter. The delivered local source is the scoped inspection
path. Its serialization trusts validated local owner objects; it does not qualify
decoded remote objects or unknown getters as original wire bytes.

The inspection collector allows at most 25 reads, 60 seconds in supplied time
and 4 MiB cumulative replies, within existing per-value limits. It creates no
watchdog. The app must cancel stalled gates, keep its original owner/session
alive until outstanding callbacks settle, and avoid blocking cancellation behind
a global mutation lock. Synchronous native SQLite reads are non-preemptible and
can advance internal clock/control state. Read-only collection is not a promise
of zero internal database writes.

## Qualification is specific

1. Core: two clean offline consumer runs, 17 checks each, with two scripted Works.
2. Core plus companion: one offline install and 17 cases/eight groups, including
   identity/access denial, bytes, omissions, refusal, expiry, withdrawal and reopen.
3. Signatures: owner-reported 67 consolidated local tests, including eight new
   account cases plus one preparation check. Its app supplies copy gates, renderer,
   Reports, cancellation and lifetime control. This result document was reviewed
   here; this preparation did not rerun the app tests or qualify a real provider.

Fixtures label scripted Agent responses and synthetic identity/consent. They do
not establish real Human consent, independent execution, model authorship,
complete private context, Report truth or observed audience pixels. Historical
M5/M6 and separately named artist/host live cases retain their own limits; they
do not establish general live-client support for this distribution.

## Responsibilities and excluded promises

The artist and coding Agent supply creative framing/rules, authentication,
enrollment/consent, app acceptance, safe rendering, Manifest selection, copy
authority, audience UI and operations. A declared Agent Participant is not
independently authenticated model authorship. A receipt establishes only its
specified receiver statement. App acceptance/transformation and observed display
are separate. Audiences interpret intention and artistic quality.

- No installed curator plugin, automatic desktop discovery/handoff, managed
  inference, real OAuth provider, production HTTPS service or host UI support is
  bundled. Inert test identity must never become real authentication.
- Arbitrary binary carriers, PNG embedding, image input, recursive artifact fetch
  and a universal SVG sanitizer/renderer are not supplied. Opaque SVG recording
  does not constrain the artist to an SDK graphics subset or make rendering safe.
- A full account selection is not full process history. Binding can be absent
  with an explicit unresolved link. A collected account alone does not establish
  that any Agent participated. Actual claims need the selected material and basis.
- Source rights are checked through the last source read; copy authority is checked
  at release. App-controlled withdrawal can stop its pending delivery. Arbitrary
  outside-native withdrawal after that last read is not atomically coupled to an
  independent allow gate. Delivered copies cannot be retracted by lease expiry.
- Native restart/reopen at the original identity/path is qualified. A relocated
  database, ordinary live external backup, restore/migration, rollback reconciliation,
  disaster recovery and permanent availability are not. The store holds exclusive
  ownership and binds local identity. Do not patch its identity rows or call a
  selected account an authoritative backup. Durable production promises need a
  separately supported recovery/custody procedure.
- No compatibility guarantee for other Node/OS/CPU combinations, browsers, Claude,
  ChatGPT, Codex, Grok or other hosts follows from this alpha's synthetic tests.
  A real artist app must qualify its own route, consent, delivery and cleanup.

Private chats, memory, hidden reasoning and unselected Works are excluded by
default. Reading may still use a Work without Participants/Acts/Relations or
storage. Minting policy belongs to the consuming app/contract. Ask your Agent
reading releases and SDK0.1.4 remain unchanged.
