# Artwork SDK Linux alpha.3

Start with one Work. [Follow the artist guide](GUIDE.md) to offer an original
mark, preserve a contribution and an optional stated intention, and inspect
the app's result. Then [carry an idea into a second Work](TWO-WORK.md). That
example shows separate permissions for reusing a quote and importing it,
plus two ways the later Work can respond to the same optional reference.

[Install and run the examples](INSTALL.md) with the platform-specific package
pair and consumer lock in this bundle.

| Component | Exact version |
| --- | --- |
| Artwork SDK | `@agent-art/artwork-sdk@0.0.0-planned-transfer.2` |
| Evidence-account module | `@agent-art/participation-account@0.0.0-account-linux.1` |
| Runtime | Ubuntu 24.04.5 arm64 with private ext4, Node 22.23.4, SQLite 3.53.4, npm 10.9.9 |

The package archives and 13-entry lock match the Linux alpha.2 release.
Both fixtures use scripted returns. The second example shows permission
checks, source attribution, declared use and reproducible app effects.
The audience interprets intention. Live participation and application
adoption have separate qualification.
