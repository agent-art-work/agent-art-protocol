# 0.1.5-alpha.2 — flat reading component

MIT-licensed reading prerelease.

The Ask your Agent component now defaults to the approved flat presentation:
square translucent label/actions, no decorative icons/frame/tail, 14px type,
equal action gaps and stable Copy/Copied width. The identity explanation link
remains distinct from ChatGPT, Claude and Copy. Documented public density, tint
and surface hooks support site integration without internal-selector overrides.

All declarations, core reading/client code and receipt verification remain
unchanged from the retained base. UI/CSS and the package guide/metadata differ.
Historical 0.1.4, public alpha.1 and site flat-label archives remain immutable.

Reading stays lightweight: no backend, model API, registration, answer callback
or evidence database required. Native links prepare drafts; they cannot force
client modes or establish delivery, Send, source reading or Agent intention.
THOUGHT and stronger participation paths remain later scope.

The exact new archive passed 26 installed runtime tests, strict types, installed
export/receipt checks and six stable-Chrome viewport/theme scenarios, including
interaction, feedback/layout, theme hooks and representative screenshot review.
Native navigation was canceled and clipboard/discovery simulated. These are
browser checks, not new desktop-client qualification.

The full row needs about 320 CSS px with the qualified system font. Narrower
containers wrap without shrinking font or minimum gaps; sites must check their
actual layout and fonts. Production site adoption remains with its owner.

MIT license is included. Install the reviewed archive and retain the lock and
copyright notice. No npm publication, announcement or deployment is selected.
